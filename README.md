# Tetris

브라우저에서 바로 실행할 수 있는 간단한 테트리스 게임입니다.
`HTML`, `CSS`, `Vanilla JavaScript`만 사용해 구현했으며, 다크 테마의 머티리얼 디자인(Material Design)을 적용했습니다 (Roboto 폰트, elevation 그림자, 카드형 패널, FAB 스타일 원형 방향 버튼).

## 파일 구성

- `index.html` / `landing.css`
  랜딩 페이지(로고, PLAY 버튼)를 정의합니다. GitHub Pages 진입점이며, PLAY 클릭 시 `game.html`로 이동합니다.

- `game.html`
  실제 게임 화면 — 보드(canvas), 점수/레벨/Next/최고점수 패널, 조작 안내, 게임오버 화면 구조를 정의합니다.

- `style.css`
  `game.html` 전용 레이아웃, 색상, 게임오버 오버레이 스타일을 담당합니다.

- `script.js`
  테트로미노 생성·이동·회전·충돌 판정, 줄 제거, 점수 계산, 게임오버·재시작 로직을 처리합니다.

## 주요 기능 (MVP)

- 7종 표준 테트로미노(I, O, T, S, Z, J, L)
- 방향키로 좌우 이동 / 소프트 드롭 / 회전, Space로 하드 드롭
- 줄이 가득 차면 자동 제거 및 점수 가산
- 30초마다 레벨이 오르고 블록 낙하 속도가 빨라짐 (화면에 Score/Level 표시)
- 다음에 나올 블록을 Next 패널에 미리보기로 표시
- 전체 최고점수를 브라우저에 저장(`localStorage`)해 세션이 끝나도 유지, 갱신 시 즉시 화면에 반영
- 보드 상단까지 쌓이면 게임오버 표시 및 재시작 버튼
- 상단 바에 언제든 누를 수 있는 "다시 시작" 버튼(게임오버를 기다리지 않고 바로 재시작)
- 반응형 레이아웃 — 좁은 화면에서 보드/패널이 세로로 쌓이고 크기가 자동 조정됨
- 터치 기기(`pointer: coarse`)에서는 화면 하단에 이동/회전/드롭용 터치 버튼이 자동으로 표시됨

고급 기능(홀드, 고스트 피스, 사운드 등)은 포함하지 않은 최소 기능 버전입니다.

## 조작 방법

| 키보드 | 터치 버튼 | 동작 |
| --- | --- | --- |
| ← / → | 방향키 ◀ / ▶ | 좌우 이동 |
| ↓ | 방향키 ▼ | 소프트 드롭 |
| ↑ | ⟲ / ⟳ (반시계·시계 방향 회전 버튼) | 회전 |
| Space | DROP | 하드 드롭 |

터치 버튼은 마우스/키보드가 없는 터치 기기에서만 보드 위에 반투명하게 떠 있는 형태로 자동 표시됩니다. 왼쪽에는 DROP 버튼과 회전 버튼 2개(반시계/시계), 오른쪽에는 좌·우·아래 이동용 방향키가 있습니다. 터치 버튼은 키보드보다 세분화되어 회전을 반시계/시계 두 방향으로 선택할 수 있습니다.

## 실행 방법

### 1) 파일 직접 열기

- `index.html`(랜딩 페이지) 파일을 브라우저에서 직접 열어 확인할 수 있습니다. PLAY 버튼을 누르면 `game.html`로 이동합니다.

### 2) 로컬 서버 실행 (권장)

아래 명령어를 `tetris` 폴더에서 실행합니다.

```bash
cd tetris
python3 -m http.server 8080
```

브라우저에서 다음 주소로 접속합니다.

- `http://localhost:8080`

## 서버 종료

- 로컬 서버를 실행한 터미널에서 `Ctrl + C`를 누르면 서버가 종료됩니다.
