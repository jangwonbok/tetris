# Tetris

브라우저에서 바로 실행할 수 있는 간단한 테트리스 게임입니다.
`HTML`, `CSS`, `Vanilla JavaScript`만 사용해 구현했습니다.

## 파일 구성

- `index.html`
  게임 보드(canvas), 점수 표시, 조작 안내, 게임오버 화면 구조를 정의합니다.

- `style.css`
  레이아웃, 색상, 게임오버 오버레이 스타일을 담당합니다.

- `script.js`
  테트로미노 생성·이동·회전·충돌 판정, 줄 제거, 점수 계산, 게임오버·재시작 로직을 처리합니다.

## 주요 기능 (MVP)

- 7종 표준 테트로미노(I, O, T, S, Z, J, L)
- 방향키로 좌우 이동 / 소프트 드롭 / 회전, Space로 하드 드롭
- 줄이 가득 차면 자동 제거 및 점수 가산
- 보드 상단까지 쌓이면 게임오버 표시 및 재시작 버튼

고급 기능(다음 블록 미리보기, 홀드, 고스트 피스, 레벨업, 사운드 등)은 포함하지 않은 최소 기능 버전입니다.

## 조작 방법

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우 이동 |
| ↓ | 소프트 드롭 |
| ↑ | 회전 |
| Space | 하드 드롭 |

## 실행 방법

### 1) 파일 직접 열기

- `index.html` 파일을 브라우저에서 직접 열어 확인할 수 있습니다.

### 2) 로컬 서버 실행 (권장)

아래 명령어를 `tetris` 폴더에서 실행합니다.

```bash
cd tetris
python3 -m http.server 8080
```

브라우저에서 다음 주소로 접속합니다.

- `http://localhost:8080`

## 서버 종료

- 로컬 서버를 실행한 터미널에서 `Ctrl + C`를 누르면 서버가 종료됩니다.
